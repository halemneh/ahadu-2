አሃዱ በአማርኛ ቃላት የሚጻፍ የፕሮግራም ቋንቋ ነው። ቁልፍ ቃላቱ፣ ተለዋጮቹ፣ እንዲሁም
የስተት መልእክቶቹ በሙሉ በግዕዝ ፊደል ናቸው።

```ahadu
ጻፍ("ሰላም ዓለም!")
```

## ለምን አሃዱ?

ፕሮግራም መማር በራሱ ከባድ ነው። በማያውቁት ቋንቋ መማር ደግሞ ሁለት ነገር በአንድ ጊዜ
እንደመማር ነው። አሃዱ የሁለተኛውን ሸክም ያነሳል።

<ul class="cards">
  <li>
    <h3>በቋንቋዎ</h3>
    <p>ቁልፍ ቃላት፣ የተግባር ስሞች እና የስተት መልእክቶች በአማርኛ።</p>
  </li>
  <li>
    <h3>ምንም ማዘጋጀት የለም</h3>
    <p>በየትምህርቱ ውስጥ ኮዱን ቀይረው ወዲያው ማሂድ ይችላሉ።</p>
  </li>
  <li>
    <h3>ግልጽ ስተቶች</h3>
    <p>እያንዳንዱ ስተት ኮድ፣ መስመር እና ዓምድ ይዞ ይመጣል።</p>
  </li>
</ul>

## ቋንቋው ምን ይመስላል?

ሁኔታው ቀድሞ፣ ቃሉ ኋላ ይመጣል — አማርኛ እንደሚናገር።

```ahadu
ዕድሜ = 20

ዕድሜ > 18 ከሆነ፦
    ጻፍ("ትልቅ ሰው")
አለበለዚያ፦
    ጻፍ("ልጅ")
```

```ውጤት
ትልቅ ሰው
```

ተግባሮችም በተመሳሳይ ይጻፋሉ።

```ahadu
ተግባር ሰላምታ(ስም)፦
    ተመላሽ "ሰላም " + ስም + "!"

ጻፍ(ሰላምታ("ዓለም"))
```

```ውጤት
ሰላም ዓለም!
```
