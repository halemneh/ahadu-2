**ተለዋጭ** ማለት ለአንድ ዋጋ የሰጡት ስም ነው። ከዚያ በኋላ በስሙ ይጠቀሙበታል።

```ahadu
ስም = "አበበ"
ዕድሜ = 25

ጻፍ(ስም፣ ዕድሜ)
```

```ውጤት
አበበ 25
```

የተለዋጭ ስም በአማርኛ ይጻፋል። `ስም`፣ `ዕድሜ`፣ `የተማሪ_ቁጥር` ሁሉም ይሰራሉ።

## መቀየር

ተለዋጭ ይባላል ምክንያቱም ዋጋው ሊቀየር ይችላል።

```ahadu
ቆጣሪ = 1
ጻፍ(ቆጣሪ)

ቆጣሪ = ቆጣሪ + 1
ጻፍ(ቆጣሪ)
```

```ውጤት
1
2
```

`ቆጣሪ = ቆጣሪ + 1` ማለት "የቆጣሪን አሁናዊ ዋጋ ወስደህ አንድ ጨምርበት፣ ውጤቱንም
በቆጣሪ ውስጥ አስቀምጥ" ማለት ነው።

## የዋጋ አይነቶች

በአሃዱ አራት መሠረታዊ አይነቶች አሉ። `አይነት` የሚባለው ተግባር የትኛው እንደሆነ ይነግርዎታል።

```ahadu
ጻፍ(አይነት(25))
ጻፍ(አይነት("አበበ"))
ጻፍ(አይነት(እውነት))
ጻፍ(አይነት([1፣ 2]))
```

```ውጤት
ቁጥር
ጽሁፍ
እውነታ
ስብስብ
```

ከላይ ያሉት አራቱ ስሞች — `ቁጥር`፣ `ጽሁፍ`፣ `እውነታ`፣ `ስብስብ` — የቋንቋው ናቸው።
ስለዚህ እንደ ተለዋጭ ስም አይጠቀሙባቸው፦

```ahadu error=AH2001
ቁጥር = 4
```

በምትኩ `አሃዝ`፣ `ተራ` ወይም ሌላ ስም ይምረጡ።

## ሒሳብ

ቁጥሮች የተለመዱትን የሒሳብ ምልክቶች ይቀበላሉ።

```ahadu
ጻፍ(7 + 2)
ጻፍ(7 - 2)
ጻፍ(7 * 2)
ጻፍ(7 / 2)
ጻፍ(7 % 2)
```

```ውጤት
9
5
14
3.5
1
```

`%` ቀሪውን ይሰጣል — 7 ለ2 ሲካፈል ቀሪው 1 ነው። ይህ አንድ ቁጥር ጥንድ መሆኑን
ለማወቅ ይጠቅማል።

## ጽሁፍ መደመር

በጽሁፎች ላይ `+` ያገናኛቸዋል።

```ahadu
የመጀመሪያ = "ተስፋ"
የአባት = "ማርያም"

ጻፍ(የመጀመሪያ + የአባት)
```

```ውጤት
ተስፋማርያም
```

ነገር ግን ቁጥርና ጽሁፍ አይደመሩም። ይህ ስተት ነው፦

```ahadu error=AH3002
ጻፍ("ዕድሜ፦ " + 25)
```

ስተቱ ምን እንደሆነ ይነግርዎታል። ከፈለጉ `ጻፍ("ዕድሜ፦"፣ 25)` ብለው ይለያዩዋቸው።

## መልመጃ

የአንድ አራት ማዕዘን ስፋትና ዙሪያ አስሉ። ርዝመቱ 7፣ ወርዱ 4 ነው።

<details class="answer">
<summary>መልሱን አሳይ</summary>

```ahadu
ርዝመት = 7
ወርድ = 4

ጻፍ("ስፋት፦"፣ ርዝመት * ወርድ)
ጻፍ("ዙሪያ፦"፣ 2 * (ርዝመት + ወርድ))
```

```ውጤት
ስፋት፦ 28
ዙሪያ፦ 22
```

</details>
