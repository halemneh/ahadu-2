አሃዱ ሊሠራ የሚችላቸው፣ ሌላ ምንም የፕሮግራም ቋንቋ ሊሠራ የማይችላቸው ሁለት ነገር።

## የግዕዝ ቁጥር መጻፍ

ከሁለተኛው ትምህርት ጀምሮ የአማርኛ ቁጥሮችን **መጻፍ** ትችል ነበር — `፳፩`
ትክክለኛ `21` ነው። `ወደግዕዝ` ተቃራኒውን ያደርጋል፦

```ahadu
ጻፍ(ወደግዕዝ(1)፣ ወደግዕዝ(7)፣ ወደግዕዝ(10)፣ ወደግዕዝ(100))
```

```ውጤት
፩ ፯ ፲ ፻
```

ስርዓቱ በቦታ ላይ የተመሠረተ አይደለም፤ የሚደመር ነው፦ `፫፻፳፩` ማለት
3×100 + 20 + 1 ነው።

```ahadu
ጻፍ(ወደግዕዝ(2017))
ጻፍ(ወደቁጥር("፳፩") + 1)
```

```ውጤት
፳፻፲፯
22
```

`ወደቁጥር`ና `ወደግዕዝ` ተቃራኒዎች ናቸው፤ ስለዚህ አንዱ የሌላውን ይፈታል።

### ለዜሮ ምልክት የለም

```ahadu error=AH3021
ጻፍ(ወደግዕዝ(0))
```

የግዕዝ ቁጥሮች የየራሳቸው ዋጋ ካላቸው ምልክቶች ተደምረው የተሠሩ ናቸው።
**ምንም**ን የሚወክል ምልክት የለም፤ ስለዚህ ዜሮ አጻጻፍ የለውም — ቁጥሮቹ
ከ`፩` ይጀምራሉ። ይህ የአጻጻፍ ስርዓቱ ባህርይ ነው፤ የአሃዱ ጉድለት አይደለም፤
ስተቱም ያንን ይናገራል። አሉታዊ ቁጥርና ክፍልፋይም አጻጻፍ የላቸውም።

## የኢትዮጵያ ዘመን አቆጣጠር

ዓመቱ **አሥራ ሦስት** ወር አለው፦ አሥራ ሁለት የሠላሳ ቀን፣ ከዚያም ጳጉሜ፤
ጳጉሜ አምስት ቀን ነው — በየአራት ዓመቱ ግን ስድስት።

```ahadu
ወር = 1
ወር <= 13 እስከሆነ ድረስ፦
    ጻፍ(ወደግዕዝ(ወር)፣ ወርመጠሪያ(ወር))
    ወር = ወር + 1
```

```ውጤት
፩ መስከረም
፪ ጥቅምት
፫ ኅዳር
፬ ታኅሣሥ
፭ ጥር
፮ የካቲት
፯ መጋቢት
፰ ሚያዝያ
፱ ግንቦት
፲ ሰኔ
፲፩ ሐምሌ
፲፪ ነሐሴ
፲፫ ጳጉሜ
```

`ዛሬ` የዛሬውን ቀን በሦስት ቁጥር ይሰጣል — ዓመት፣ ወር፣ ቀን፦

```ahadu
ቀኑ = ዛሬ()
ጻፍ(ወርመጠሪያ(ቀኑ[1]) + " " + ወደግዕዝ(ቀኑ[2]) + " ቀን " + ወደግዕዝ(ቀኑ[0]))
```

ይህ ገጽ ለዚህ መልስ በፈቃድ አያረጋግጥልህም። "አሂድ" ተጫን — የዛሬውን ቀን
የሚናገር ገጽ ነገ ይሳሳታል። (እንደ ያለፈው ትምህርቱ ዘር፣ `ዛሬ` ሰነዱ ሲሠራ
ቋሚ ጊዜ ያነባል፤ በመጫወቻው ላይ ግን እውነተኛውን ሰዓት።)

ቀን የሦስት ቁጥር ስብስብ ብቻ ነው፤ ስለዚህ አስቀድመህ የምታውቀው ሁሉ
ይሠራበታል። `ቀኑ[1]` ወሩ ነው፤ ቦታ ከ0 ስለሚጀምር።

## ከግሪጎሪ አቆጣጠር መቀየር

`ከግሪጎሪ` የግሪጎሪውን ዓመት፣ ወርና ቀን ይቀበላል፦

```ahadu
ጻፍ(ከግሪጎሪ(2024፣ 9፣ 11))
```

```ውጤት
[2017፣ 1፣ 1]
```

መስከረም 1 ቀን 2017 ዓ.ም. በግሪጎሪ አቆጣጠር መስከረም 11 ቀን 2024 ነበር —
የኢትዮጵያ አዲስ ዓመት። የኢትዮጵያው ዓመት ከግሪጎሪው በሰባት ወይም
በስምንት ዓመት ወደኋላ ነው፤ ይህም ከመስከረም 1 በየትኛው ጎን እንደሆንክ
ይወሰናል፦

```ahadu
ጻፍ(ከግሪጎሪ(2026፣ 1፣ 1))
```

```ውጤት
[2018፣ 4፣ 23]
```

አዲስ ዓመትም ሁልጊዜ በአንድ የግሪጎሪ ቀን ላይ አይውልም። መስከረም 11 ነው፤
ተከትሎ የሚመጣው የካቲት 29 ቀን ሲኖረው ግን 12 ይሆናል፦

```ahadu
ጻፍ(ከግሪጎሪ(2023፣ 9፣ 12))
ጻፍ(ከግሪጎሪ(2024፣ 9፣ 11))
```

```ውጤት
[2016፣ 1፣ 1]
[2017፣ 1፣ 1]
```

የሌለ ቀን ግምት አይሆንም፤ ስተት ነው፦

```ahadu error=AH3022
ጻፍ(ከግሪጎሪ(2024፣ 2፣ 31))
```

## መልመጃ

የዛሬውን ቀን ሙሉ ዓረፍተ ነገር አድርገህ ጻፍ፤ ቀኑና ዓመቱ በግዕዝ ቁጥር
ይሁኑ።

<details class="answer">
<summary>መልሱን አሳይ</summary>

```ahadu
ቀኑ = ከግሪጎሪ(2024፣ 9፣ 11)

ጻፍ("ዛሬ " + ወርመጠሪያ(ቀኑ[1]) + " " + ወደግዕዝ(ቀኑ[2]) + " ቀን " + ወደግዕዝ(ቀኑ[0]) + " ዓ.ም. ነው።")
```

```ውጤት
ዛሬ መስከረም ፩ ቀን ፳፻፲፯ ዓ.ም. ነው።
```

መልሱ ገጹ እንዲያረጋግጠው ቋሚ ቀን ያለው `ከግሪጎሪ` ይጠቀማል። `ዛሬ()` ን
አስገብተህ ራስህ አሂደው።

</details>
