በየፕሮግራሙ የሚመጡ ሥራዎች አሉ። አሃዱ እነዚህን አስቀድሞ ጽፎ ያመጣል — ወዲያው
በስማቸው ትጠቀማለህ፤ ምንም ማዘጋጀት ወይም ማስገባት አያስፈልግም።

## ከስብስብ ጋር መሥራት

```ahadu
ዋጋዎች = [12፣ 7፣ 30፣ 5]

ጻፍ("ድምር፦"፣ ደምር(ዋጋዎች))
ጻፍ("ትልቁ፦"፣ ከፍተኛው(ዋጋዎች))
ጻፍ("ትንሹ፦"፣ ዝቅተኛው(ዋጋዎች))
ጻፍ("አማካይ፦"፣ ደምር(ዋጋዎች) / ርዝመት(ዋጋዎች))
```

```ውጤት
ድምር፦ 54
ትልቁ፦ 30
ትንሹ፦ 5
አማካይ፦ 13.5
```

በአምስተኛው ትምህርት ስብስብ መደመር ዑደትና ቆጣሪ ይፈልግ ነበር። ዑደቱ አሁንም አለ —
ልዩነቱ `ደምር` ውስጥ መሆኑ ነው።

`ፈልግ` ነገሩ **የት** እንዳለ ይናገራል፤ `ቁጠር` ስንት ጊዜ እንዳለ ይቆጥራል፦

```ahadu
ፊደሎች = ["ሀ"፣ "ለ"፣ "ሐ"፣ "ለ"]

ጻፍ(ፈልግ(ፊደሎች፣ "ሐ"))
ጻፍ(ቁጠር(ፊደሎች፣ "ለ"))
ጻፍ(ፈልግ(ፊደሎች፣ "ዘ"))
```

```ውጤት
2
2
ምንም
```

ነገሩ ከሌለ `ፈልግ` `ምንም` ይመልሳል። እንደ ሌሎች ቋንቋዎች `-1` አይመልስም፤
ምክንያቱም በአሃዱ `-1` እውነተኛ ቦታ ነው — የመጨረሻው — ስለዚህ "አልተገኘም"
ለማለት መጠቀም ስህተተኛውን ዕቃ በዝምታ ይሰጥህ ነበር።

## መደርደር ስብስቡን ይቀይረዋል

```ahadu
ቁጥሮች = [3፣ 9፣ 1፣ 4]
ደርድር(ቁጥሮች)
ጻፍ(ቁጥሮች)

ገልብጥ(ቁጥሮች)
ጻፍ(ቁጥሮች)
```

```ውጤት
[1፣ 3፣ 4፣ 9]
[9፣ 4፣ 3፣ 1]
```

`ደርድር`ና `ገልብጥ` ትዕዛዝ ናቸው — እንደ `አዋህድ`ና `ሰርዝ` የሰጠሃቸውን ስብስብ
ይቀይሩና `ምንም` ይመልሳሉ። ዋናውን ማቆየት ከፈለክ ቅጂውን ደርድር፦

```ahadu
ዋናው = [3፣ 9፣ 1]
ተደርድሯል = ቅጂ(ዋናው)
ደርድር(ተደርድሯል)

ጻፍ("ዋናው፦"፣ ዋናው)
ጻፍ("ቅጂው፦"፣ ተደርድሯል)
```

```ውጤት
ዋናው፦ [3፣ 9፣ 1]
ቅጂው፦ [1፣ 3፣ 9]
```

## ሙሉ ቁጥር

ማካፈል ሁልጊዜ ክፍልፋይ ይሰጣል፦

```ahadu
ጻፍ(7 / 2)
```

```ውጤት
3.5
```

ሙሉ ቁጥር ሲያስፈልግ የትኛውን አቅጣጫ እንደምትፈልግ ተናገር፦

```ahadu
ጻፍ(ወደታች(7 / 2))
ጻፍ(ወደላይ(7 / 2))
ጻፍ(አቅርብ(3.5)፣ አቅርብ(3.4))
ጻፍ(ፍጹም(0 - 7))
```

```ውጤት
3
4
4 3
7
```

`ወደታች` ወደታች ያወርዳል፣ `ወደላይ` ወደላይ ያወጣል፣ `አቅርብ` ወደ ቀረበው ይሄዳል፣
`ፍጹም` ደግሞ ቁጥሩ ከዜሮ ያለውን ርቀት ይሰጣል — ስለዚህ የመቀነስ ምልክቱን
ይጥላል።

## ጽሁፍ መክፈልና ማገናኘት

`ከፋፍል` ጽሁፍን ይከፋፍላል፤ `አገናኝ` ስብስብን መልሶ ያገናኛል፦

```ahadu
መስመር = "አበበ ከበደ አስቴር"
ስሞች = ከፋፍል(መስመር)

ጻፍ(ርዝመት(ስሞች))
ጻፍ(ስሞች[0])
ጻፍ(አገናኝ(ስሞች፣ "፣ "))
```

```ውጤት
3
አበበ
አበበ፣ ከበደ፣ አስቴር
```

በአንድ ግቤት `ከፋፍል` ክፍተት ባለበት ይከፋፍላል፤ ይህም ከመስመር ቃላትን ለማንበብ
የሚያስፈልገው ነው። በተወሰነ ቦታ ለመክፈል ሁለተኛ ግቤት ስጠው፦

```ahadu
ጻፍ(ከፋፍል("ሀ,ለ,ሐ"፣ ","))
```

```ውጤት
["ሀ"፣ "ለ"፣ "ሐ"]
```

`ከርክም` ደግሞ ከጽሁፉ ጫፎች ያለውን ክፍተት ያስወግዳል — ሰው የጻፈውን ለማጽዳት
ይጠቅማል፦

```ahadu
ጻፍ("[" + ከርክም("   ሰላም   ") + "]")
```

```ውጤት
[ሰላም]
```

## ለየዋጋው ስም፦ ካርታ

ስብስብ ነገሮችን በቦታ ያገኛል። አንዳንድ ጊዜ በስም ማግኘት ትፈልጋለህ — ለየሰው
ዕድሜ፣ ለየቡድን ነጥብ። ያ `ካርታ` ነው።

```ahadu
ዕድሜ = ካርታ()

ዕድሜ.አስገባ("አበበ"፣ 22)
ዕድሜ.አስገባ("ከበደ"፣ 30)

ጻፍ(ዕድሜ.አግኝ("አበበ"))
ጻፍ(ዕድሜ.አለው("ዘለቀ"))
ጻፍ(ዕድሜ.ብዛት())
```

```ውጤት
22
ሃሰት
2
```

ነጥቡ አንድ ነገር ሥራ እንዲሠራ የምትጠይቅበት መንገድ ነው፦ `ዕድሜ.አግኝ("አበበ")`
ማለት "ዕድሜ፣ አበበን አግኝልኝ" ነው። `አስገባ` ጥንድ ያስቀምጣል፣ `አግኝ` ያወጣል፣
`አለው` ስሙ መኖሩን ይናገራል፣ `አውጣ` ጥንዱን ያስወግዳል፣ `ብዛት` ይቆጥራል፣
`ቁልፎቹ` ደግሞ ስሞቹን ሁሉ ይሰጣል፦

```ahadu
ነጥብ = ካርታ()
ነጥብ.አስገባ("ቀይ"፣ 3)
ነጥብ.አስገባ("ሰማያዊ"፣ 5)

ነጥብ.ቁልፎቹ() ለእያንዳንዱ ቡድን፦
    ጻፍ(ቡድን፣ ነጥብ.አግኝ(ቡድን))
```

```ውጤት
ቀይ 3
ሰማያዊ 5
```

ያንኑ ስም ሁለተኛ ጊዜ ማስገባት አዲስ ጥንድ አይጨምርም፤ የነበረውን ዋጋ ይተካል፦

```ahadu
ዕድሜ = ካርታ()
ዕድሜ.አስገባ("አበበ"፣ 22)
ዕድሜ.አስገባ("አበበ"፣ 23)

ጻፍ(ዕድሜ.አግኝ("አበበ")፣ ዕድሜ.ብዛት())
```

```ውጤት
23 1
```

## እነዚህ በአሃዱ ተጽፈዋል

`ደምር` ቋንቋው እንደገለጸው በትክክል ይኸው ነው፦

```ahadu
ተግባር ደምር(ዝርዝር)፦
    ድምሩ = 0
    ዝርዝር ለእያንዳንዱ ዕቃ፦
        ድምሩ = ድምሩ + ዕቃ
    ተመላሽ ድምሩ

ጻፍ(ደምር([1፣ 2፣ 3]))
```

```ውጤት
6
```

ይህ ትርጉሙ አይደለም — ኮዱ ራሱ ነው። `ደምር`፣ `ቁጠር`፣ `ፈልግ`፣ `ከፍተኛው`፣
`ዝቅተኛው`፣ `ደርድር`፣ `ገልብጥ`ና `ካርታ` ሁሉም በአሃዱ ተጽፈዋል — አስቀድመህ
ባወቅሃቸው ዑደትና ሁኔታ። ሁሉንም ማንበብ ትችላለህ፤ ብትፈልግም ራስህ
ትጽፋቸው ነበር።

ጥቂቶቹ — `ወደታች`፣ `ከፋፍል`፣ `ወደቁጥር` — በቋንቋው የተጻፉ አይደሉም፤ የቋንቋው
ራሱ ክፍል ናቸው፤ ምክንያቱም አሃዱ መግለጽ የማይችለውን ነገር ያደርጋሉ።

## መልመጃ

በክፍተት የተለያዩ ቁጥሮች ያለው መስመር ጠይቅ፤ ስንት እንደሆኑ፣ ድምራቸውንና
ትልቁን ጻፍ።

<details class="answer">
<summary>መልሱን አሳይ</summary>

```ahadu
መስመር = አንብብ("ቁጥሮች፦ ")
ቁጥሮች = []

ከፋፍል(መስመር) ለእያንዳንዱ ክፍል፦
    ቁጥርነው(ክፍል) ከሆነ፦
        አዋህድ(ቁጥሮች፣ ወደቁጥር(ክፍል))

ርዝመት(ቁጥሮች) == 0 ከሆነ፦
    ጻፍ("ምንም ቁጥር አልተገኘም።")
አለበለዚያ፦
    ጻፍ("ብዛት፦"፣ ርዝመት(ቁጥሮች))
    ጻፍ("ድምር፦"፣ ደምር(ቁጥሮች))
    ጻፍ("ትልቁ፦"፣ ከፍተኛው(ቁጥሮች))
```

```ግቤት
12 7 30 5
```

```ውጤት
ቁጥሮች፦ ብዛት፦ 4
ድምር፦ 54
ትልቁ፦ 30
```
