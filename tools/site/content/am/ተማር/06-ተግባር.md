አንድ ዓይነት ኮድ ደጋግመው ሲጽፉ ካዩ፣ ስም ሰጥተው አንድ ጊዜ ይጻፉት። ይህ **ተግባር**
ይባላል።

```ahadu
ተግባር ሰላምታ(ስም)፦
    ጻፍ("ሰላም"፣ ስም)

ሰላምታ("አበበ")
ሰላምታ("አልማዝ")
```

```ውጤት
ሰላም አበበ
ሰላም አልማዝ
```

`ተግባር` ይጀምራል፣ ከዚያ ስሙ፣ ከዚያ በቅንፍ ውስጥ የሚቀበለው **ግብዓት**።

## ዋጋ መመለስ

ተግባር ዋጋ መመለስ ይችላል። `ተመላሽ` ይጠቀሙ።

```ahadu
ተግባር ድምር(ሀ፣ ለ)፦
    ተመላሽ ሀ + ለ

ውጤት = ድምር(3፣ 4)
ጻፍ(ውጤት)
ጻፍ(ድምር(10፣ 20))
```

```ውጤት
7
30
```

`ተመላሽ` ሲደርስ ተግባሩ ወዲያው ይቆማል።

```ahadu
ተግባር ትልቁ(ሀ፣ ለ)፦
    ሀ > ለ ከሆነ፦
        ተመላሽ ሀ
    ተመላሽ ለ

ጻፍ(ትልቁ(12፣ 7))
ጻፍ(ትልቁ(3፣ 9))
```

```ውጤት
12
9
```

## ለምን ይጠቅማል

ተግባር ሦስት ነገር ይሰጣል፦

1. **ድግግሞሽ ያስወግዳል** — አንድ ጊዜ ጽፈው ብዙ ጊዜ ይጠቀማሉ
2. **ስም ይሰጣል** — `ትልቁ(ሀ፣ ለ)` ከሦስት መስመር ኮድ ይልቅ ግልጽ ነው
3. **አንድ ቦታ ያስተካክላሉ** — ስተት ቢኖር የሚታረመው አንድ ቦታ ነው

## ራሱን የሚጠራ ተግባር

ተግባር ራሱን መጥራት ይችላል።

```ahadu
ተግባር ፋክቶሪያል(ቁ)፦
    ቁ <= 1 ከሆነ፦
        ተመላሽ 1
    ተመላሽ ቁ * ፋክቶሪያል(ቁ - 1)

ጻፍ(ፋክቶሪያል(5))
```

```ውጤት
120
```

`ፋክቶሪያል(5)` → `5 * ፋክቶሪያል(4)` → `5 * 4 * ፋክቶሪያል(3)` … እስከ 1
ድረስ ይወርዳል። ያ **መቆሚያ** ሁኔታ ከሌለ ግን አያቆምም።

## ግብዓት ከተጠቃሚ

`አንብብ` ከተጠቃሚው ይቀበላል።

```ahadu
ስም = አንብብ("ስምህ ማን ነው? ")
ጻፍ("እንኳን ደህና መጣህ"፣ ስም)
```

```ግቤት
ኃይለሚካኤል
```

```ውጤት
ስምህ ማን ነው? እንኳን ደህና መጣህ ኃይለሚካኤል
```

ይህን ስናሂድ መልሱ ይጠየቃል።
