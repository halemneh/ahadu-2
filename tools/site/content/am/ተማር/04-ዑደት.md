አንድ ነገር አሥር ጊዜ ለመጻፍ አሥር መስመር መጻፍ አያስፈልግም። **ዑደት** ይጠቀሙ።

```ahadu
ቆጣሪ = 1

ቆጣሪ <= 5 እስከሆነ ድረስ፦
    ጻፍ(ቆጣሪ)
    ቆጣሪ = ቆጣሪ + 1
```

```ውጤት
1
2
3
4
5
```

እንደ ሁኔታው ሁሉ፣ እዚህም ሁኔታው ቀድሞ ይመጣል፦ "ቆጣሪ ከ5 ያነሰ ወይም እኩል
**እስከሆነ ድረስ**"።

## እንዴት እንደሚሠራ

ሦስት ነገሮች ያስፈልጋሉ፦

1. **መነሻ** — `ቆጣሪ = 1`
2. **ሁኔታ** — `ቆጣሪ <= 5`፤ እውነት እስከሆነ ድረስ ይደገማል
3. **ለውጥ** — `ቆጣሪ = ቆጣሪ + 1`፤ ይህ ከሌለ ዑደቱ አያልቅም

ሦስተኛውን መርሳት የተለመደ ስተት ነው። ቢረሱት ፕሮግራሙ አያቆምም — አሃዱ ግን
ከብዙ እርምጃ በኋላ ያቆመውና ይነግርዎታል።

## ድምር ማስላት

```ahadu
ቁ = 1
ድምር = 0

ቁ <= 10 እስከሆነ ድረስ፦
    ድምር = ድምር + ቁ
    ቁ = ቁ + 1

ጻፍ("ከ1 እስከ 10 ድምር፦"፣ ድምር)
```

```ውጤት
ከ1 እስከ 10 ድምር፦ 55
```

## የማባዛት ሰንጠረዥ

```ahadu
ተራ = 1

ተራ <= 5 እስከሆነ ድረስ፦
    ጻፍ(7፣ "x"፣ ተራ፣ "="፣ 7 * ተራ)
    ተራ = ተራ + 1
```

```ውጤት
7 x 1 = 7
7 x 2 = 14
7 x 3 = 21
7 x 4 = 28
7 x 5 = 35
```

## ዑደት ውስጥ ሁኔታ

ዑደትና ሁኔታ አብረው ይሠራሉ።

```ahadu
ቁ = 1

ቁ <= 10 እስከሆነ ድረስ፦
    ቁ % 2 == 0 ከሆነ፦
        ጻፍ(ቁ፣ "ጥንድ")
    ቁ = ቁ + 1
```

```ውጤት
2 ጥንድ
4 ጥንድ
6 ጥንድ
8 ጥንድ
10 ጥንድ
```

ልብ ይበሉ — `ጻፍ` ሁለት ጊዜ ወደ ውስጥ ገብቷል፤ አንዱ ለዑደቱ፣ አንዱ ለሁኔታው።

## ለእያንዳንዱ

ስብስብን ወይም ጽሁፍን ለመዞር ቆጣሪ አያስፈልግም። `ለእያንዳንዱ` አለ።

```ahadu
"አሃዱ" ለእያንዳንዱ ፊደሉ፦
    ጻፍ(ፊደሉ)
```

```ውጤት
አ
ሃ
ዱ
```

እንደ ሌሎቹ ሁሉ የሚዞረው ነገር ቀድሞ ይመጣል፦ "አሃዱ **ለእያንዳንዱ** ፊደሉ"።

ከላይ የተማርናቸው ሦስት ነገሮች — መነሻ፣ ሁኔታና ለውጥ — በዚህ ቅርጽ አያስፈልጉም፤
አሃዱ ራሱ ይይዛቸዋል። ስለዚህ ሦስተኛውን መርሳት የሚያመጣው ስተት በዚህ ዑደት
ፈጽሞ አይከሰትም።

ስብስብም እንዲሁ ይዞራል፦

```ahadu
ዋጋዎች = [12፣ 7፣ 30]
ድምር = 0

ዋጋዎች ለእያንዳንዱ ዋጋ፦
    ድምር = ድምር + ዋጋ

ጻፍ("ድምር፦"፣ ድምር)
```

```ውጤት
ድምር፦ 49
```

ስለ ስብስብ በሚቀጥለው ትምህርት በሰፊው እንማራለን።

### የቱን እጠቀም?

- **ለእያንዳንዱ** — ስብስብ ወይም ጽሁፍ ስትዞር። ይህ አብዛኛው ጊዜ ነው።
- **እስከሆነ ድረስ** — ሁኔታው ከስብስብ ጋር ያልተያያዘ ሲሆን፣ ወይም ቦታው ራሱ
  ሲያስፈልግ።
