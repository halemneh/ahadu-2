እስካሁን ያየናቸው ፕሮግራሞች ቁጥሮቻቸውን ራሳቸው ያውቃሉ። `አንብብ` ፕሮግራሙን
የሚያሄደውን ሰው ይጠይቃል።

```ahadu
ጻፍ("ስምህ ማን ነው?")
ስም = አንብብ("ስም፦ ")
ጻፍ("እንደምን አለህ " + ስም + "!")
```

```ግቤት
አበበ
```

```ውጤት
ስምህ ማን ነው?
ስም፦ እንደምን አለህ አበበ!
```

`አንብብ` አንድ መስመር ያነባል። የሰጠኸው ጽሁፍ አስቀድሞ ይጻፋል — ጥያቄ ሆኖ። ስለዚህ
`ስም፦` እና መልሱ በአንድ መስመር ላይ ይሆናሉ።

## የሚጻፈው ሁሉ ጽሁፍ ነው

ይህ ሁሉንም ሰው የሚያጋጥም ነገር ነው። ሰው የጻፈውን ቁጥር ላይ 1 ለመጨመር ሞክር፦

```ahadu error=AH3002
ዕድሜ = አንብብ("ዕድሜ፦ ")
ጻፍ(ዕድሜ + 1)
```

```ግቤት
22
```

`አንብብ` ሁልጊዜ **`ጽሁፍ`** ይመልሳል — ሰውዬው አኃዝ ቢጽፍም። እና `ጽሁፍ`ና `ቁጥር`
አይደመሩም፤ ይህ የሁለተኛው ትምህርት ህግ ነበር፣ እና እዚህ እየጠበቀህ ነው።
`"22" + 1` ትክክለኛ መልስ የለውም፦ `23` ይሁን ወይስ `"221"`?

## ወደቁጥር

ስለዚህ የፈለከውን ትናገራለህ።

```ahadu
ዕድሜ = ወደቁጥር(አንብብ("ዕድሜ፦ "))
ጻፍ("በሚቀጥለው ዓመት"፣ ዕድሜ + 1)
```

```ግቤት
22
```

```ውጤት
ዕድሜ፦ በሚቀጥለው ዓመት 23
```

`ወደቁጥር` ጽሁፍ ተቀብሎ የሚወክለውን ቁጥር ይሰጣል። በዙሪያው ያለውን ክፍተት
ይቀበላል፤ ስለዚህ `" 22 "` ችግር አይደለም — ጥያቄ ላይ የሚጽፍ ሰው መጠንቀቅ
አይገባውም። የአማርኛን ቁጥሮችም ያነባል፤ ስለዚህ `፳፪` ይሠራል።

`ወደጽሁፍ` ደግሞ ተቃራኒውን ያደርጋል — ቁጥሩን ረዥም ጽሁፍ ውስጥ ማስገባት ስትፈልግ፦

```ahadu
ነጥብ = 17
ጻፍ("ነጥብህ " + ወደጽሁፍ(ነጥብ) + " ነው።")
```

```ውጤት
ነጥብህ 17 ነው።
```

> ሁልጊዜ አያስፈልግም። `ጻፍ("ነጥብህ"፣ ነጥብ፣ "ነው።")` ያንኑ ይጽፋል፤ ምክንያቱም
> `ጻፍ` ብዙ ዋጋ ይቀበልና በመካከላቸው ክፍተት ያደርጋል። `ወደጽሁፍ` የሚያስፈልገው
> አንድ ጽሁፍ **ስትሠራ** ነው።

## ቁጥር ባይጽፉ

`ወደቁጥር("ሰላም")` ስተት ነው፤ ይህም በፈቃድ ነው — በዝምታ የሚቀጥል ማስያ
መልስ ይጽፍና ታምነዋለህ። ነገር ግን ስተት ፕሮግራሙን ያቆማል፤ ይህም
የምትፈልገው አይደለም።

አስቀድመህ ጠይቅ። `ቁጥርነው` `ወደቁጥር` ይሠራ አይሠራ ይነግርሃል፦

```ahadu
መልስ = አንብብ("ቁጥር ጻፍ፦ ")

ቁጥርነው(መልስ) ከሆነ፦
    ጻፍ("እጥፉ"፣ ወደቁጥር(መልስ) * 2)
አለበለዚያ፦
    ጻፍ("ያ ቁጥር አይደለም።")
```

```ግቤት
ሰላም
```

```ውጤት
ቁጥር ጻፍ፦ ያ ቁጥር አይደለም።
```

`ቁጥርነው` ምን ቢሰጠውም ፈጽሞ አይሳሳትም። ሥራው ይኸው ነው፦ ራሱ ፕሮግራሙን
ሊያቆም የሚችል ጠባቂ ጠባቂ አይሆንም።

## መልመጃ

ሁለት ቁጥር ጠይቅና ድምራቸውን ጻፍ። አንዱ ቁጥር ካልሆነ ያንን ተናገር።

<details class="answer">
<summary>መልሱን አሳይ</summary>

```ahadu
አንደኛው = አንብብ("አንደኛው፦ ")
ሁለተኛው = አንብብ("ሁለተኛው፦ ")

ቁጥርነው(አንደኛው) እና ቁጥርነው(ሁለተኛው) ከሆነ፦
    ድምሩ = ወደቁጥር(አንደኛው) + ወደቁጥር(ሁለተኛው)
    ጻፍ("ድምር፦"፣ ድምሩ)
አለበለዚያ፦
    ጻፍ("ሁለቱም ቁጥር መሆን አለባቸው።")
```

```ግቤት
12
30
```

