`አጋጣሚ` በሰጠኸው ሁለት ቁጥር መካከል ያለ ቁጥር ይመርጣል።

```ahadu
ጻፍ(አጋጣሚ(1፣ 6))
```

```ውጤት
4
```

ሁለቱም ጫፎች ይቆጠራሉ፤ ስለዚህ `አጋጣሚ(1፣ 6)` በእውነት ዳይስ ነው — ስድስቱም
ጎኖች፣ አምስት አይደለም። ጥቂት ጊዜ ጣለው፦

```ahadu
ዙር = 1
ዙር <= 5 እስከሆነ ድረስ፦
    ጻፍ(አጋጣሚ(1፣ 6))
    ዙር = ዙር + 1
```

```ውጤት
4
1
4
6
6
```

## ገጹ የጣለውን ለምን ያውቃል

ይህ ሊያስገርምህ ይገባል። አጋጣሚ ከሆነ ገጹ መልሱን አስቀድሞ እንዴት ይናገራል?

ምክንያቱም `አጋጣሚ` ፍጹም አጋጣሚ አይደለም። **ዘር** ከሚባል መነሻ ቁጥር
ተነስቶ የሚሰላ ቅደም ተከተል ይከተላል፤ ዘሩን የሚመርጠው ፕሮግራምህን
የሚያሄደው ነው። መጫወቻውና በተርሚናል ያለው `ahadu` ሰዓቱን ይጠቀማሉ፤
ስለዚህ በየጊዜው የተለየ ይወጣል። **ይህ ገጽ ግን ቋሚ ዘር ይጠቀማል** —
ስለዚህ `4` ን ሊያረጋግጥልህ ይችላል።

ይህ ለትምህርቶቹ የተደረገ ዘዴ አይደለም። በዚህ ሰነድ ያለው የአሃዱ ኮድ ሁሉ
ሰነዱ ሲሠራ በእውነት ይሄዳል፤ ውጤቱም ገጹ ከሚለው ካልሆነ ሰነዱ አይሠራም።
በሰዓት ላይ የተመሠረተ ዘር ያንን ማረጋገጫ ጀማሪዎች በሚያስፈልጋቸው ቦታ
ባዶ ያደርገው ነበር።

ከላይ ባለው ኮድ ላይ "አሂድ" ተጫን — የተለየ ቁጥር ታገኛለህ። ገጹና
መጫወቻው በፈቃድ አይስማሙም።

## ዘሩን ራስህ መምረጥ፦ ዘር

`ዘር` ዘሩን ከፕሮግራምህ ውስጥ ያስቀምጣል፤ ይህም ቅደም ተከተሉን ያስደግመዋል፦

```ahadu
ዘር(7)
ጻፍ(አጋጣሚ(1፣ 100)፣ አጋጣሚ(1፣ 100))

ዘር(7)
ጻፍ(አጋጣሚ(1፣ 100)፣ አጋጣሚ(1፣ 100))
```

```ውጤት
2 7
2 7
```

ያው ዘር፣ ያው ቁጥር። ይህ ከሚመስለው የበለጠ ይጠቅማል፦ የሚበላሽ ጨዋታ
ሁለት ጊዜ ባንድ መንገድ ማበላሸት ስትችል ማስተካከል በጣም ይቀላል።

`ዘር` እንደ `አዋህድ` ትዕዛዝ ነው — አንድ ነገር ይቀይርና `ምንም` ይመልሳል።
ስለዚህ `ሀ = ዘር(7)` `ሀ` ላይ `ምንም` ያስቀምጣል፤ ቁጥር አይደለም።

## የወጣውን መቁጠር

```ahadu
ጎኖች = [0፣ 0፣ 0፣ 0፣ 0፣ 0]
ዙር = 1

ዙር <= 60 እስከሆነ ድረስ፦
    ጎን = አጋጣሚ(1፣ 6)
    ጎኖች[ጎን - 1] = ጎኖች[ጎን - 1] + 1
    ዙር = ዙር + 1

ጻፍ(ጎኖች)
ጻፍ(ደምር(ጎኖች))
```

```ውጤት
[9፣ 13፣ 10፣ 8፣ 11፣ 9]
60
```

ስድሳ ጊዜ በስድስት ጎን ሲከፋፈል በአማካይ አሥር ይሆናል፤ አንዳቸውም ብዙ
አልራቁም። `ጎን - 1` ያለው ዳይስ ከ1 ሲጀምር ስብስብ ከቦታ 0 ስለሚጀምር ነው።

## መልመጃ

የግምት ጨዋታ ጻፍ፦ ከ1 እስከ 20 ቁጥር ምረጥ፣ ለተጫዋቹ አምስት ሙከራ ስጥ፣
በየግምቱ ቁጥሩ ከዚያ የሚበልጥ ወይም የሚያንስ መሆኑን ንገረው።

```ahadu
ሚስጥር = አጋጣሚ(1፣ 20)
ቀሪ = 5
አገኘ = ሃሰት

ጻፍ("ከ1 እስከ 20 መረጥኩ። አምስት ሙከራ አለህ።")

ቀሪ > 0 እና ተቃርኖ አገኘ እስከሆነ ድረስ፦
    መልስ = አንብብ("ግምትህ፦ ")
    ቀሪ = ቀሪ - 1

    ተቃርኖ ቁጥርነው(መልስ) ከሆነ፦
        ጻፍ("ቁጥር ጻፍ።")
    አለበለዚያ፦
        ግምት = ወደቁጥር(መልስ)
        ግምት == ሚስጥር ከሆነ፦
            አገኘ = እውነት

            ጻፍ("ከዚህ ይበልጣል። ቀሪ፦"፣ ቀሪ)
        አለበለዚያ፦

    ጻፍ("ቁጥሩ"፣ ሚስጥር፣ "ነበር።")
```
