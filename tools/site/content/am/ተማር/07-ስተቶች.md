ስተት መሥራት የመማር አካል ነው። ጥሩው ዜና አሃዱ ምን እንደተፈጠረ በግልጽ መናገሩ ነው።

እያንዳንዱ ስተት ሦስት ነገር ይዟል፦ **ኮድ**፣ **መልእክት**፣ እና **ቦታ**።

```ahadu error=AH3001
ጻፍ(ያልተሰየመ)
```

`AH3001` ኮዱ ነው። መልእክቱ ችግሩን ይናገራል። መስመሩና ዓምዱ የት እንደሆነ ይጠቁማሉ።

## ሦስት ዓይነት ስተት

ኮዱ በሚጀምርበት ቁጥር ስተቱ **መቼ** እንደተገኘ ይታወቃል።

### AH1 — የቃላት ስተት

ፕሮግራሙ ወደ ቃላት ሲከፋፈል የሚገኝ። ያልታወቀ ምልክት ሲገባ፦

```ahadu error=AH1001
ሀ = 5 $ 3
```

ወይም ክፍተቱ ሲሳሳት፦

```ahadu error=AH1002
ሀ = 1
  ለ = 2
```

### AH2 — የአገባብ ስተት

ቃላቱ ትክክል ሆነው አደራደራቸው ሲሳሳት፦

```ahadu error=AH2002
ጻፍ("ያልተዘጋ"
```

እነዚህ ሁለቱ ፕሮግራሙ **ከመጀመሩ በፊት** ይገኛሉ። ስለዚህ አንድም መስመር
ሳይሄድ ይነገርዎታል።

### AH3 — የአሂድ ስተት

ፕሮግራሙ እየሄደ ሳለ የሚከሰት። እስከዚያ ድረስ ያለው ሁሉ ይሄዳል።

```ahadu error=AH3003
ጻፍ("ከዚህ በፊት ይሄዳል")
ጻፍ(10 / 0)
```

በዜሮ ማካፈል በመጻፍ ጊዜ አይታወቅም — አካፋዩ ዜሮ መሆኑ የሚታወቀው ሲሄድ ነው።
ለዚህ ነው AH3 የሆነው።

## የተለመዱ ስተቶች

| ኮድ | ትርጉም |
| --- | --- |
| `AH3001` | ያልተሰየመ ተለዋጭ ተጠርቷል |
| `AH3002` | አይነቶቹ የማይፈቅዱት ሥራ — ጽሁፍና ቁጥር መደመር |
| `AH3003` | በዜሮ ተካፍሏል |
| `AH3008` | ከስብስቡ ውጭ ያለ ቦታ ተጠይቋል |
| `AH3019` | `ወደ_ቁጥር` ቁጥር ያልሆነ ጽሁፍ ተሰጥቶታል |
| `AH1002` | የመስመር መጀመሪያ ክፍተት ተሳስቷል |
| `AH2002` | ቅንፍ አልተዘጋም |

ሙሉው ዝርዝር በ[ማጣቀሻው](/am/ማጣቀሻ/) ውስጥ አለ።

### በእይታ ማወቅ የሚገባቸው ሁለት

`AH3002`ና `AH3019` ከግቤት ማንበብ የሚመጡት ሁለቱ ናቸው፤ አብረውም የጀማሪ
ስተቶችን አብዛኛውን ይይዛሉ፦

```ahadu error=AH3019
ጻፍ(ወደ_ቁጥር("ሰላም"))
```

`ወደ_ቁጥር` ቁጥር የማይወክል ነገር ተሰጥቶታል። ከመቀየር በፊት በ`ቁጥር_ነው` ጠብቅ —
"መጠየቅ" የሚለው ትምህርት እንዴት እንደሆነ ያሳያል።

### ስሙ ቀድሞ ተግባር የነበረ ጊዜ

ይህ አንድ ጊዜ እስካላየኸው ድረስ ግራ ያጋባል፦

```ahadu error=AH3013
ርዝመት = 5
ጻፍ(ርዝመት("ሰላም"))
```

`ርዝመት` ቋንቋው ቀድሞ የሞላልህ ተራ ስም ነው፤ ስለዚህ ዋጋ **መስጠት ትችላለህ** —
ከዚያ ግን ቁጥር ይሆናል፣ ቁጥርም ሊጠራ አይችልም። አሃዱ ይህን ያስተውልና
የትኛውን ተግባር እንደተኩህ ይነግርሃል። መፍትሔው ሁልጊዜ ለተለዋጭህ ሌላ ስም
መስጠት ነው።

## ስተትን እንዴት ማስተካከል

1. **ኮዱን ያንብቡ** — AH1 ወይስ AH3 መሆኑ የት እንደሚፈልጉ ይነግርዎታል
2. **ወደ መስመሩ ይሂዱ** — ስተቱ የተጠቆመው ቦታ ላይ ይጀምሩ
3. **አንድ ነገር ብቻ ይቀይሩ** — ከዚያ እንደገና ያሂዱ

ከላይ ያሉትን ምሳሌዎች ያስተካክሏቸው። ለምሳሌ የመጀመሪያውን `ያልተሰየመ`
ከመጥራት በፊት ዋጋ ይስጡት።

## መልመጃ

ይህ ፕሮግራም ሦስት ስተት አለው። ያግኙና ያስተካክሉ።

```ahadu error=AH1002
ድምር = 0
ቁ = 1

  ቁ <= 3 እስከሆነ ድረስ
    ድምር = ድምር + ቁ
```

<details class="answer">
<summary>መልሱን አሳይ</summary>

ስተቶቹ፦ አላስፈላጊ ክፍተት፣ የጎደለ `፦`፣ እና ቆጣሪው አለመጨመሩ።

```ahadu
ድምር = 0
ቁ = 1

ቁ <= 3 እስከሆነ ድረስ፦
    ድምር = ድምር + ቁ
    ቁ = ቁ + 1

ጻፍ(ድምር)
```

```ውጤት
6
```

</details>
