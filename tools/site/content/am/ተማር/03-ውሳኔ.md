ፕሮግራም ሁልጊዜ ከላይ ወደ ታች ብቻ አይሄድም። አንዳንድ ጊዜ "ይህ እውነት ከሆነ ይህን
አድርግ" ማለት ያስፈልጋል።

```ahadu
ዕድሜ = 20

ዕድሜ > 18 ከሆነ፦
    ጻፍ("ትልቅ ሰው")
```

```ውጤት
ትልቅ ሰው
```

## ሁኔታው ቀድሞ ይመጣል

ይህ የአሃዱ ዋና ልዩነት ነው። በእንግሊዝኛ ላይ በተመሠረቱ ቋንቋዎች "if age > 18"
ይባላል — ቃሉ ቀድሞ፣ ሁኔታው ኋላ። በአማርኛ ግን እንዲህ አንናገርም። "ዕድሜው ከ18
በላይ **ከሆነ**" እንላለን — ሁኔታው ቀድሞ፣ ቃሉ ኋላ።

አሃዱ የሚከተለው አማርኛውን ነው፦

```ahadu fragment
ዕድሜ > 18 ከሆነ፦
```

ስለዚህ ኮዱን በድምጽ ሲያነቡት እንደ ዓረፍተ ነገር ይሰማል። `፦` ደግሞ "ይህን
ተከትሎ የሚመጣው…" ማለት ነው።

## ሁለት መንገድ

ሁኔታው እውነት ካልሆነ ምን ይሁን? `አለበለዚያ` ይላል።

```ahadu
ዕድሜ = 12

ዕድሜ > 18 ከሆነ፦
    ጻፍ("ትልቅ ሰው")
አለበለዚያ፦
    ጻፍ("ልጅ")
```

```ውጤት
ልጅ
```

## ከሁለት በላይ

`ግን` ተጨማሪ ሁኔታ ይጨምራል። ልብ ይበሉ — `ግን` ቀድሞ፣ ሁኔታው ከዚያ፣ `ከሆነ`
ኋላ ይመጣል።

```ahadu
ነጥብ = 75

ነጥብ > 89 ከሆነ፦
    ጻፍ("ኤ")
ግን ነጥብ > 79 ከሆነ፦
    ጻፍ("ቢ")
ግን ነጥብ > 69 ከሆነ፦
    ጻፍ("ሲ")
አለበለዚያ፦
    ጻፍ("ወድቋል")
```

```ውጤት
ሲ
```

ከላይ ወደ ታች ይፈተሻል። የመጀመሪያው እውነት የሆነው ይሄዳል፤ የቀሩት አይታዩም።

## የማነጻጸሪያ ምልክቶች

| ምልክት | ትርጉም |
| --- | --- |
| `>` | ይበልጣል |
| `<` | ያንሳል |
| `>=` | ይበልጣል ወይም እኩል ነው |
| `<=` | ያንሳል ወይም እኩል ነው |
| `==` | እኩል ነው |
| `!=` | እኩል አይደለም |

`=` እና `==` የተለያዩ ናቸው። `=` ዋጋ ያስቀምጣል፤ `==` ያነጻጽራል።

## ሁኔታዎችን ማገናኘት

`እና`፣ `ወይም`፣ `አይደለም` ሁኔታዎችን ያገናኛሉ።

```ahadu
ዕድሜ = 25
ሥራ = እውነት

ዕድሜ > 18 እና ሥራ ከሆነ፦
    ጻፍ("ብድር ይፈቀዳል")
```

```ውጤት
ብድር ይፈቀዳል
```

## ክፍተት ይቆጠራል

ከ`፦` በኋላ ያለው መስመር ወደ ውስጥ መግባት አለበት። የገባው ሁሉ የዚያ ሁኔታ አካል ነው።

```ahadu
አሃዝ = 4

አሃዝ % 2 == 0 ከሆነ፦
    ጻፍ("ጥንድ ነው")
    ጻፍ("ይህም የሁኔታው አካል ነው")

ጻፍ("ይህ ግን ሁልጊዜ ይጻፋል")
```

```ውጤት
ጥንድ ነው
ይህም የሁኔታው አካል ነው
ይህ ግን ሁልጊዜ ይጻፋል
```

## መልመጃ

አንድ ቁጥር ጥንድ ወይም ጎዶሎ መሆኑን የሚናገር ፕሮግራም ይጻፉ።
