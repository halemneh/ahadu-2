የፕሮግራም ቋንቋ መማር ሲጀምሩ የሚጻፈው የመጀመሪያው ፕሮግራም አንድ ነገር ማሳየት ነው።
በአሃዱ ይህ `ጻፍ` በሚባል ተግባር ይሆናል።

```ahadu
ጻፍ("ሰላም ዓለም!")
```

```ውጤት
ሰላም ዓለም!
```

**አሂድ** የሚለውን ይጫኑ። ከዚያ ኮዱን ቀይረው እንደገና ያሂዱ።

## ጽሑፍ

በጥቅስ ምልክት `"` መካከል ያለው ሁሉ **ጽሑፍ** ይባላል። ጽሑፍ ማንኛውንም ፊደል
ሊይዝ ይችላል።

```ahadu
ጻፍ("አዲስ አበባ")
ጻፍ("Addis Ababa")
ጻፍ("፩፪፫")
```

```ውጤት
አዲስ አበባ
Addis Ababa
፩፪፫
```

እያንዳንዱ `ጻፍ` በአዲስ መስመር ይጽፋል።

## ከአንድ በላይ ነገር መጻፍ

`ጻፍ` ከአንድ በላይ ነገር መቀበል ይችላል። በ`፣` ይለያያሉ።

```ahadu
ጻፍ("ስም፦"፣ "አበበ")
```

```ውጤት
ስም፦ አበበ
```

በመካከላቸው ክፍተት ራሱ ይጨመራል።

## አስተያየት

በ`#` የሚጀምር መስመር **አስተያየት** ነው። ኮምፒውተሩ አያነበውም፤ ለሰው ነው።

```ahadu
# ይህ መስመር አይሄድም
ጻፍ("ይህ ግን ይሄዳል")
```

```ውጤት
ይህ ግን ይሄዳል
```

አስተያየት ኮድዎ ለምን እንደዚያ እንደተጻፈ ለመግለጽ ይጠቅማል።

## መልመጃ

ስምዎን እና ከተማዎን በሁለት መስመር የሚጽፍ ፕሮግራም ይጻፉ።

<details class="answer">
<summary>መልሱን አሳይ</summary>

```ahadu
ጻፍ("ስም፦"፣ "ኃይለሚካኤል")
ጻፍ("ከተማ፦"፣ "አዲስ አበባ")
```

```ውጤት
ስም፦ ኃይለሚካኤል
ከተማ፦ አዲስ አበባ
```

</details>
