ከዚህ በፊት ፕሮግራም ጽፈው የማያውቁ ከሆነ፣ ከዚህ ይጀምሩ። በዚህ ገጽ ላይ ያለው ምንም ነገር
ቀዳሚ እውቀት አይጠይቅም።

## ፕሮግራም ማለት የትእዛዞች ዝርዝር ነው

ኮምፒውተር ያሰቡትን አይገምትም። የነገሩትን፣ በነገሩት ቅደም ተከተል፣ ልክ እንደተጻፈ ይፈጽማል፤
ከዚያ ውጭ ምንም አያደርግም።

ዋናው ሐሳብ ይኸው ነው። ፕሮግራም ማለት ተጽፎ የተቀመጠ የትእዛዞች ዝርዝር ሲሆን፣ ኮምፒውተሩ
ከላይ ጀምሮ አንድ በአንድ ያልፍባቸዋል።

ሁለት ትእዛዞች ያሉት ፕሮግራም እነሆ፦

```ahadu
ጻፍ("አንድ")
ጻፍ("ሁለት")
```

```ውጤት
አንድ
ሁለት
```

`ጻፍ` ማለት መጻፍ ነው። እያንዳንዱ መስመር አንድ ነገር ይጽፋል።

## ቅደም ተከተሉ ራሱ ፕሮግራሙ ነው

ሁለቱን መስመሮች ቢቀያይሯቸው ሌላ ፕሮግራም ይሆናል፦

```ahadu
ጻፍ("ሁለት")
ጻፍ("አንድ")
```

```ውጤት
ሁለት
አንድ
```

ምንም ድንቅ ነገር አልተፈጸመም፤ ኮምፒውተሩ መጀመሪያ የመጀመሪያውን መስመር፣ ቀጥሎም ሁለተኛውን
ሠራ። አብዛኛው የፕሮግራም ሥራ ምን መሆን እንዳለበትና በምን ቅደም ተከተል እንደሆነ መወሰን ነው።

## ይሞክሩት

በእነዚህ ትምህርቶች ውስጥ ያለ እያንዳንዱ ኮድ ሊሄድና ሊስተካከል ይችላል።

ከላይ ባለው ፕሮግራም ላይ **▸ አሂድ** የሚለውን ይጫኑ። ከዚያም በጥቅስ ምልክት ውስጥ ካሉት
ቃላት አንዱን ቀይረው እንደገና ያሂዱት።

ምንም ነገር ማበላሸት አይችሉም። ፕሮግራሙ የሚሄደው በራስዎ አሳሽ ውስጥ ነው፤ ወደ የትም
አይላክም፤ ምንም አይቀመጥም፤ ገጹን እንደገና ሲጭኑት ዋናው ኮድ ይመለሳል።

## ኮምፒውተር ቃል በቃል ነው

ቋንቋው የማያውቀውን ነገር ቢጽፉ አይገምትም፦

```ahadu error=AH3001
ጻፍ(ሰላም)
```

እዚህ ላይ `ሰላም` የጥቅስ ምልክት የለውም፤ ስለዚህ አሃዱ የአንድ ነገር ስም መስሎት ፈለገው፤
ግን አላገኘም። ይህንንም ይናገራል፤ የት እንደሆነም ይነግርዎታል።

ስህተት ውድቀት አይደለም። ቋንቋው ሊሠራው ያልቻለውን እየነገረዎት ነው፤ ይህ ደግሞ ዝም ብሎ
ተሳስቶ ከመቀጠል እጅግ ይሻላል። ብዙ ስህተቶችን ያያሉ፤ የመጨረሻውም ትምህርት ስለማንበባቸው
ነው።
