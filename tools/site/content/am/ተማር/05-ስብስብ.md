እስካሁን አንድ ተለዋጭ አንድ ዋጋ ይዟል። ግን የአንድ ክፍል ተማሪዎችን ስም ማስቀመጥ
ቢፈልጉስ? **ስብስብ** ይጠቀሙ።

```ahadu
ተማሪዎች = ["አበበ"፣ "ከበደ"፣ "አልማዝ"]

ጻፍ(ተማሪዎች)
ጻፍ("ብዛት፦"፣ ርዝመት(ተማሪዎች))
```

```ውጤት
["አበበ"፣ "ከበደ"፣ "አልማዝ"]
ብዛት፦ 3
```

ልብ ይበሉ — ጽሁፍ ለብቻው ሲጻፍ ጥቅሱ አይታይም፤ በስብስብ ውስጥ ሲሆን ግን ይታያል።
ይህ ሆን ተብሎ ነው፦ በስብስቡ ውስጥ ያለው ቁጥር 3 ወይስ ጽሁፍ "3" መሆኑን ያሳያል።

## አንድ ነገር ማውጣት

እያንዳንዱ ነገር **ቦታ** አለው። ቆጠራው ከ**ዜሮ** ይጀምራል።

```ahadu
ተማሪዎች = ["አበበ"፣ "ከበደ"፣ "አልማዝ"]

ጻፍ(ተማሪዎች[0])
ጻፍ(ተማሪዎች[2])
ጻፍ(ተማሪዎች[-1])
```

```ውጤት
አበበ
አልማዝ
አልማዝ
```

ከዜሮ መጀመሩ መጀመሪያ ላይ እንግዳ ይመስላል፤ ግን ይለመዳል። `-1` ከመጨረሻው
ይቆጥራል።

የሌለ ቦታ ከጠየቁ ስተት ነው፦

```ahadu error=AH3008
ተማሪዎች = ["አበበ"፣ "ከበደ"]
ጻፍ(ተማሪዎች[5])
```

## ቁራጭ ማውጣት

```ahadu
ቁጥሮች = [10፣ 20፣ 30፣ 40፣ 50]

ጻፍ(ቁጥሮች[1:3])
ጻፍ(ቁጥሮች[:2])
ጻፍ(ቁጥሮች[3:])
```

```ውጤት
[20፣ 30]
[10፣ 20]
[40፣ 50]
```

`[1:3]` ማለት "ከቦታ 1 ጀምሮ እስከ 3 በፊት" ማለት ነው — መጀመሪያው ይገባል፣
መጨረሻው አይገባም።

## መቀየርና መጨመር

ስብስብ **ይቀየራል**።

```ahadu
ቁጥሮች = [1፣ 2፣ 3]

ቁጥሮች[0] = 99
ጻፍ(ቁጥሮች)

ጨምር(ቁጥሮች፣ 4)
ጻፍ(ቁጥሮች)

ሰርዝ(ቁጥሮች፣ 0)
ጻፍ(ቁጥሮች)
```

```ውጤት
[99፣ 2፣ 3]
[99፣ 2፣ 3፣ 4]
[2፣ 3፣ 4]
```

ጽሁፍ ግን አይቀየርም። `ስም[0] = "ለ"` ስተት ነው — በምትኩ አዲስ ጽሁፍ ይሠራል።

## በዑደት ማንበብ

ስብስብን ለመዞር `ለእያንዳንዱ` ይቀላል — በአራተኛው ትምህርት እንደተመለከትነው።

```ahadu
ዋጋዎች = [12፣ 7፣ 30፣ 5]
ድምር = 0

ዋጋዎች ለእያንዳንዱ ዋጋ፦
    ድምር = ድምር + ዋጋ

ጻፍ("ድምር፦"፣ ድምር)
ጻፍ("አማካይ፦"፣ ድምር / ርዝመት(ዋጋዎች))
```

```ውጤት
ድምር፦ 54
አማካይ፦ 13.5
```

### ቦታው ራሱ ሲያስፈልግ

`ለእያንዳንዱ` ዕቃውን ይሰጣል፤ ቦታውን አይሰጥም። ቦታው ሲያስፈልግ ቆጣሪ ያለው
ዑደት ተጠቀም፦

```ahadu
ስሞች = ["አበበ"፣ "ከበደ"፣ "አስቴር"]
ቦታ = 0

ቦታ < ርዝመት(ስሞች) እስከሆነ ድረስ፦
    ጻፍ(ቦታ + 1፣ ስሞች[ቦታ])
    ቦታ = ቦታ + 1
```

```ውጤት
1 አበበ
2 ከበደ
3 አስቴር
```

ቦታን ከዜሮ ጀምሮ እስከ ርዝመቱ ድረስ መቁጠር — ይህ ቅርጽ ከ`ለእያንዳንዱ` በፊት
ስብስብ ለማንበብ **ያለው ብቸኛው** መንገድ ነበር። አሁንም ቦታው ሲያስፈልግ
ይጠቅማል።
